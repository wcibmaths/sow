Step 8 — Remember term toggles across re-renders

Replace the existing toggleTerm function entirely with:

js
function toggleTerm(termId,term){
  const body=document.getElementById(termId);
  const header=body?body.previousElementSibling:null;
  if(!body||!header)return;
  const collapsed=body.classList.toggle('collapsed');
  header.classList.toggle('collapsed',collapsed);
  if(term&&tvFocus.closedTerms){
    if(collapsed) tvFocus.closedTerms.add(term); else tvFocus.closedTerms.delete(term);
  }
}

toggleTerm is called from one place only (the term header in renderTeacher), which Step 4 already updated to pass the second argument.
