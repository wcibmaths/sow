REMOVE DUPLICATION BETWEEN NEEDS ATTENTION AND CLASSES BEHIND PACE

The current Needs Attention panel repeats information already shown in Classes Behind Pace.

Change their purposes.

Rename:
“Needs Attention” to “Action Required”
“Classes Behind Pace” to “Teaching Pace”

ACTION REQUIRED

Only show items requiring meaningful teacher action.

Include:

assessments taking place within the next 7 days
classes significantly behind the planned SOW
classes behind pace with an assessment approaching
overdue or other genuinely urgent curriculum issues

Do not show every class that is only 1 or 2 lessons behind.

Suggested pace rules:

1 lesson behind: Teaching Pace table only
2 lessons behind: Teaching Pace table only
3 or more lessons behind: also show in Action Required
if an assessment is approaching and the class is behind, show it in Action Required regardless of the threshold

GENERAL
Preserve the existing visual style.
Do not change any SOW, assessment or exam data.
Do not change the existing navigation or filters.
Make the dashboard faster to scan.
Avoid large empty areas inside cards.
Ensure the layout remains responsive on smaller screens.
Test that internal scrolling does not cause the whole dashboard card to expand.

One extra point I would challenge: I would not make “2 lessons behind” automatically a warning. At the start of term, timetable variation, trips, assemblies and different lesson allocations will create small differences. If every two-lesson difference becomes an alert, the dashboard will train you to ignore alerts. The Action Required section should be reserved for things that genuinely need intervention.
