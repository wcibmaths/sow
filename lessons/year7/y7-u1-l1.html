Create a 6-slide PowerPoint lesson for Year 7 Maths (approx. age 11–12) on "Averages and Range". Include: (1) Title + Explore hook: "What is the average number of computers per household?"; (2) Warm-up activity: ordering numbers, finding smallest/largest/most common from a set; (3) Teach – mode and range using shoe size class data (include worked example); (4) Teach – median for odd and even data sets, with a number-line visual and worked example; (5) Teach – mean, with a step-by-step calculation visual; (6) Plenary – return to Explore question, then Reflect prompt. Use clear diagrams, friendly tone, age-appropriate language. No clipart.

Objectives & Prior Knowledge

Learning Objectives

  • Find the mode, median and range of a set of data
  • Calculate and interpret the mean of a set of data
  • Compare sets of data using averages and range
  • Solve problems involving mean, mode, median and range

Prior Knowledge / Fluency Check

  • Find the smallest, largest and most common number in a set
  • Order positive integers on a number line
  • Find the positive difference between two numbers
  • Use ordinal numbers (3rd, 6th, etc.)

Lesson Flow — 50 minutes
0 – 8 min
Starter

Explore Hook + Warm-up

  • Display Explore question: "What is the average number of computers per household?" — ask students what 'average' means to them. Don't answer yet — return at plenary.
  • Warm-up on mini-whiteboards: give a set of numbers → ask for smallest, largest, most common. Introduce the phrase 'occurs most often'.
  • Quick ordering race: 5 numbers on the board → students order in 30 seconds.
8 – 25 min
Teach

Main Teaching — Mode → Range → Median → Mean

  • Mode: Define as 'most common'. Collect class shoe sizes → identify mode. Ask: "What do you think the mode would be for a Year 11 class?" Introduce qualitative vs quantitative data.
  • Range: Define. Find range of shoe sizes. Emphasise range = one number (not "5 to 12 cm").
  • Median (Concrete): 5 students by height order → find middle by counting from both ends. Extend to 6 students → mark two middle heights on board → find halfway value. Stress: order first always.
  • Mean: Work through a class example — sum all values ÷ number of values. Students estimate before calculating (mean must be between min and max).
  • Work through Q1–Q4 together; establish that range is undefined for qualitative data (Q3 Discussion).
25 – 42 min
Practice

Independent & Supported Practice

  • Students work through Q5–Q13 from Maths Progress International p.XX. Circulate — check Q5–Q7: are they ordering before finding median?
  • Q6 Discussion: "What fraction of values are less than the median?" Draw vertical line through ordered set on board.
  • Q7: Median = 2.5 children — discuss why non-integer medians are still meaningful.
  • Q9: Prompt students to estimate first; remind mean must be between 4 and 10.
  • Q11: Remind students to count zeros in the total — don't ignore them.
  • Investigation (Q12–Q13): Problem-solving — finding data sets with same mode and median; range of 0 → all values equal.
Q12 Support: Show sum of four values = 4 × 6 = 24.  |  Q13a: Range of 0 → all numbers identical.
42 – 50 min
Plenary

Explore Return + Reflect

  • Return to Explore: Which average would you use for computers per household? — guide students to the mean (needs only total households + total computers; median/mode require ordering every household).
  • Ask: "What would the mean NOT tell you?" → households with zero computers.
  • Reflect: Students write one thing they already knew + one new thing they learned. Share 2–3 responses. Emphasise links to prior knowledge.
  • Set homework: ActiveCourse Lesson 1.1 / Workbook p.1–4.
♿
Adaptive Teaching

🟢 Support

  • Provide pre-ordered data sets for Q5–Q7 to reduce cognitive load
  • Number line 0–100 available for ordering tasks
  • Q9: order values first, then find mode and median together
  • Q12: scaffold — show that 4 × mean = total sum
  • Cube towers (concrete) for median — find the middle tower physically

🟣 Stretch

  • Q8: estimate mean before calculating — explain estimation strategy
  • Q12: what values of n make the mean > 6 or < 6?
  • Design a data set where mode > median
  • Design a data set where range < mode
  • Explain why internet providers might prefer to advertise mean vs. median

🔴 Common Misconceptions

  • Median: Forgetting to order data first — use cube tower concrete activity
  • Range: Describing as "5 to 12" instead of 7 — emphasise it's a single number
  • Mean: Dividing by wrong count (especially when zeros present)
  • Two modes: Some students think bimodal data has no mode

🔵 AFL / EAL

  • Key vocab on board throughout: mode, median, mean, range
  • Cold-call mini-whiteboard checks after each average taught
  • Q6 Discussion: use visual (vertical line through data) to support EAL students
  • Exit card: give five numbers → students write mode, median, mean, range
  • Paired talk before whole-class sharing for EAL/quieter students
