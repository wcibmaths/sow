✦ AI Slide Prompt — copy into ChatGPT / Copilot / Gemini
Create a 6-slide PowerPoint lesson for Year 7 Maths (approx. age 11–12) on "Averages and Range". Include: (1) Title + Explore hook: "What is the average number of computers per household?"; (2) Warm-up activity: ordering numbers, finding smallest/largest/most common from a set; (3) Teach – mode and range using shoe size class data (include worked example); (4) Teach – median for odd and even data sets, with a number-line visual and worked example; (5) Teach – mean, with a step-by-step calculation visual; (6) Plenary – return to Explore question, then Reflect prompt. Use clear diagrams, friendly tone, age-appropriate language. No clipart.

Objectives & Prior Knowledge

Learning Objectives

  • Find the mode, median and range of a set of data
  • Calculate and interpret the mean of a set of data
  • Compare sets of data using averages and range
  • Solve problems involving mean, mode, median and range

Prior Knowledge / Fluency Check

  • Find the smallest, largest and most common number in a set
  • Order positive integers on a number line
  • Find the positive difference between two numbers
  • Use ordinal numbers (3rd, 6th, etc.)

Lesson Flow — 50 minutes
▼
0 – 8 min
Starter

Explore Hook + Warm-up

  • Display Explore question: "What is the average number of computers per household?" — ask what 'average' means to them. Don't answer yet — return at plenary.
  • Mini-whiteboards: give a set of numbers → ask for smallest, largest, most common. Introduce 'occurs most often'.
  • Quick ordering race: 5 numbers on board → students order in 30 seconds.
8 – 25 min
Teach

Main Teaching — Mode → Range → Median → Mean

  • Mode: 'Most common'. Collect class shoe sizes → find mode. Ask: "Mode for a Year 11 class?" Qualitative vs quantitative data.
  • Range: Find range of shoe sizes. Emphasise range = one number, not "5 to 12 cm".
  • Median (Concrete): 5 students by height → find middle. Extend to 6 → mark two middle heights → find halfway. Order first — always.
  • Mean: Sum all values ÷ count. Students estimate before calculating.
  • Work through Q1–Q4 together. Establish range undefined for qualitative data (Q3 Discussion).
25 – 42 min
Practice

Independent & Supported Practice

  • Students work through Q5–Q13. Circulate — check ordering before median (Q5–Q7).
  • Q6: Draw vertical line through ordered set — "What fraction are less than the median?"
  • Q7: Median = 2.5 children — discuss why non-integer medians are still valid.
  • Q9: Estimate first; mean must sit between 4 and 10.
  • Q11: Count zeros — don't ignore them in the total.
  • Investigation Q12–Q13: Data sets with same mode and median; range of 0 → all values equal.
Q12 Support: sum of four values = 4 × 6 = 24  |  Q13a: Range of 0 → all numbers identical
42 – 50 min
Plenary

Explore Return + Reflect

  • Return to Explore: Which average for computers per household? → Mean (needs only totals; median/mode require every household ordered).
  • "What would the mean NOT tell you?" → households with zero computers.
  • Reflect: One thing already known + one new thing. Share 2–3 responses.
  • Set homework: ActiveCourse Lesson 1.1 / Workbook p.1–4.
♿
Adaptive Teaching
▼

🟢 Support

  • Pre-ordered data sets for Q5–Q7 to reduce cognitive load
  • Number line 0–100 available for ordering tasks
  • Q9: order values first, then find mode and median together
  • Q12: scaffold — 4 × mean = total sum
  • Cube towers (concrete) for median — find middle tower physically

🟣 Stretch

  • Q8: estimate mean before calculating — explain strategy
  • Q12: what values of n make mean > 6 or < 6?
  • Design a data set where mode > median
  • Design a data set where range < mode
  • Why might broadband providers prefer mean vs. median?

🔴 Common Misconceptions

  • Median: Not ordering first — use cube tower activity
  • Range: Writing "5 to 12" instead of 7 — it's one number
  • Mean: Wrong count when zeros are present
  • Two modes: Some think bimodal = no mode

🔵 AFL / EAL

  • Key vocab on board throughout: mode, median, mean, range
  • Mini-whiteboard cold-call after each average taught
  • Q6: vertical-line visual supports EAL students
  • Exit card: five numbers → write all four measures
  • Paired talk before whole-class sharing
